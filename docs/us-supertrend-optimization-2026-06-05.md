# 美股 SuperTrend 优化专项报告（2026-06-05）

## 范围与口径

- 研究对象：watchlist 缓存数据中 `assetBucket=us_etf` 与 `assetBucket=us_stock`。
- 美股 ETF 样本：`QQQ`, `SPY`，共 2 只。
- 美股个股样本：`AAPL`, `GOOGL`, `NVDA`, `TSLA`，共 4 只。
- 回测区间：`2021-06-04` 至 `2026-06-05`。
- 执行口径：收盘确认信号，下一交易日开盘执行；周线信号在周线收盘后第一个日线开盘执行。
- 成本口径：单边手续费 `5 bps`，单边滑点 `5 bps`。
- 评价主指标：平均收益/最大回撤比（avg return/drawdown ratio），辅看平均收益、平均最大回撤、年度稳定性与相对 buy-and-hold 的胜出数量。

注意：美股样本数量很小，结论适合作为当前 watchlist 产品参数决策，不应外推为全市场统计结论。

解读：

- `ST(10,3)` 不适合替代 ETF 默认参数。ETF 从 `ST(7,3)` 切到 `ST(10,3)` 后，avg R/DD 从 `5.37` 降至 `3.77`，avg max DD 从 `11.99%` 升至 `16.16%`。
- 个股可考虑 `ST(10,3)`：相对 `ST(7,3)`，avg return 从 `147.26%` 升至 `163.79%`，avg R/DD 从 `4.24` 升至 `4.74`，median R/DD 从 `1.93` 升至 `2.55`。
- 周线过滤不是默认增强项。`weekly+daily` 在 ETF 上几乎消灭收益，在个股上明显牺牲收益；它更像“强约束风控模式”，不适合作为默认进出场逻辑。
- BB squeeze p20 过滤不适合产品化为默认入场条件。它显著降低交易机会和收益，ETF 与个股的 R/DD 都低于 daily ST baseline。

## 可执行结论

1. 美股 ETF：保留默认 `ST(7,3)`。
   - 理由：网格最优；avg R/DD `5.37` 明显高于 `ST(10,3)` 的 `3.77`；2/2 ETF 的 R/DD 均跑赢 buy-and-hold。

2. 美股个股：`ST(10,3)` 值得继续，但先不要直接全量默认产品化。
   - 理由：网格最优，avg R/DD `4.74` 高于 `ST(7,3)` 的 `4.24`，median R/DD 也从 `1.93` 升至 `2.55`。
   - 保留限制：样本只有 4 只，且 TSLA 退化明显；NVDA 对均值贡献很大。
   - 建议形态：先做研究/灰度参数，或在美股个股页面展示“ST(10,3) 候选信号”与默认 `ST(7,3)` 并列对照。

3. 周线过滤：不要作为默认产品规则。
   - ETF：`weekly+daily ST(7,3)` avg return `-0.99%`，R/DD `-0.13`。
   - 个股：`weekly+daily ST(7,3)` avg return `90.81%`，低于 daily baseline `147.26%`；R/DD `2.47` 低于 `4.24`。
   - 可保留为可选风控视角：适合用户主动选择“只做周线同向”的保守模式，不适合作为默认入场/出场条件。

4. BB p20 / weekly+BB p20：暂不产品化。
   - ETF：daily+BB p20 R/DD `2.00`，显著低于 baseline `5.37`。
   - 个股：daily+BB p20 R/DD `0.93`，weekly+daily+BB p20 R/DD `1.19`，都明显低于 baseline。
   - 结论：当前 BB squeeze 更像“减少交易”的条件，不是有效增强条件。

5. `dailyStNoChaseAtr1`：暂不产品化。
   - 两个美股分层全周期结果均为 `0` 交易/收益，说明当前阈值过严或与 next-open 执行口径不匹配。

## 下一步建议

1. 扩大美股样本池后复跑：至少加入行业 ETF、成长/价值/防御类 ETF，以及 30-100 只高流动性美股个股，再验证 `ST(10,3)` 是否仍为个股最优。
2. 对个股参数做稳健性检验：按行业、市值、波动率、趋势强度分层，重点检查 `ST(10,3)` 是否只是由 NVDA 这类超强趋势股驱动。
3. 若要产品化个股 `ST(10,3)`，建议先以实验标签上线：展示 `ST(7,3)` 与 `ST(10,3)` 双信号、双收益/回撤摘要，不改变主策略默认。
4. 暂缓开发周线过滤、BB squeeze p20、ATR no-chase 作为默认规则；如要保留，可做成研究开关或高级筛选项。
