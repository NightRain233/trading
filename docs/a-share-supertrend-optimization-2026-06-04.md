# A 股 SuperTrend 优化专项 2026-06-04

本报告只研究现有观察池中的 A 股相关分桶：`a_share_etf` 与 `a_share_stock`。没有修改主后端策略、前端、数据库，也没有修改 `scripts/compare_supertrend_timeframes.py`。

## 研究口径

- 数据来源：`backend/watchlist.json` 中的观察池，以及 `backend/data/*.parquet` 本地缓存。
- 回测脚本：`scripts/compare_supertrend_timeframes.py`。
- 回测区间：`2021-06-04` 至 `2026-06-04`。
- 成本：单边手续费 `5 bps`，单边滑点 `5 bps`。
- 执行：日线信号收盘确认，下一根日线开盘执行；周线信号在周线收盘后第一根日线开盘执行。
- 默认参数：`ST(7,3)`。
- A 股分桶规则沿用脚本：`.SS/.SZ` 且代码以 `15/51/56/58` 开头为 `a_share_etf`，其余为 `a_share_stock`。因此 `513xxx` 跨境 ETF 也属于交易所 ETF 分桶；`000001.SS`、`000300.SS` 这类指数按脚本规则落在 `a_share_stock`，解读个股结论时需要注意这一点。

## 跑过的命令

```bash
uv run --directory backend python ../scripts/compare_supertrend_timeframes.py --annual --param-grid --include-rows --json > /tmp/a_share_supertrend_full_2026_06_04.json
```

```bash
uv run --directory backend python ../scripts/compare_supertrend_timeframes.py --st-length 10 --st-multiplier 3 --json > /tmp/a_share_supertrend_st10_3_2026_06_04.json
```

解析命令使用 `jq` 和 `node` 读取上述 `/tmp` JSON，只做汇总，不写入项目文件。

## 可执行结论

1. A 股 ETF：保留默认日线 `ST(7,3)`。

   它是完整参数网格中 ETF 分桶的最优参数，平均收益 `57.66%`、平均 R/DD `2.24`。周线 + 日线 ST 可作为防守视角，但不替代默认；BB p20/p30 不进入产品默认逻辑。

2. A 股个股：`ST(10,3)` 值得继续研究，但暂不产品化为默认。

   `ST(10,3)` 的平均 R/DD 最好，`2.96`，但中位收益和中位 R/DD 不强，且跑赢买持数量少。建议只在个股专项研究视图中展示或离线跟踪，不要改主策略参数。

3. 周线过滤：ETF 可作为低回撤/防守模式，个股暂不作为硬过滤。

   ETF 上 `周线 + 日线 ST` 把平均回撤从 `28.32%` 降到 `20.05%`，但收益也从 `57.66%` 降到 `40.44%`。个股上 `周线 + 日线 ST` 明显弱于周线 ST 和日线 ST，不建议产品化为个股默认过滤。

4. BB 过滤：A 股 ETF 和个股都暂不产品化。

   ETF 的 `daily BB p20` 平均收益只有 `14.01%`，个股只有 `5.98%` 且中位收益为负。`weekly + BB p20` 更弱。BB squeeze 在 A 股样本中更像过度过滤，不像 crypto 专项里的有效精选器。

5. 暂不产品化方向：

   - A 股全市场默认切换到 `ST(10,3)`。
   - A 股个股强制周线过滤。
   - A 股默认 BB p20/p30 入场过滤。
   - `dailyStNoChaseAtr1`。该规则在本轮 A 股汇总中基本 0 交易/0 收益，过严。

## 下一步建议

1. 产品侧先保持默认 A 股 ETF 雷达为 `ST(7,3)`，不要改主策略。
2. 如果要做研究模式，优先做只读展示：
   - ETF：`daily ST(7,3)`、`weekly + daily ST(7,3)`。
   - 个股：`daily ST(7,3)`、`daily ST(10,3)`、`weekly ST(7,3)`。
3. 个股专项需要更干净的样本：把指数、ETF、ST 股票、强周期大涨样本拆开，否则平均值容易被少数标的主导。
4. 在产品化前补充样本外验证：至少分 2021-2023 训练观察、2024-2026 验证观察，避免用同一段行情挑参数。
