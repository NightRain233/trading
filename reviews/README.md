# 复盘记录

分析任何标的之前，先检查最近 3 天的复盘文件，了解当前判断和决策。

- 每日复盘：`reviews/YYYY-MM-DD.md`
- 持仓总览：`reviews/持仓总览.md`，只汇总当前仓位、止损和风险
- 单品种页面：`reviews/<名称-代码>.md`，保存该品种当前有效的操作规则

使用 `ls reviews/` 浏览，按需读取。

## 分析前校验

1. 核对品种名称、代码和交易所后缀，例如 `588890.SS`、`159583.SZ`。
2. 确认品种页 frontmatter、标题、持仓总览和行情文件使用同一代码。
3. 记录行情截止日期；每日复盘中的指标必须来自该日期的完整收盘数据。
4. 每日复盘与品种页冲突时，以品种页的当前有效规则为准，并立即同步日记摘要。

## 执行口径

- “突破、跌破、站稳”默认指日线收盘确认，下一交易日执行；盘中触发会单独注明。
- EMA、ST、ATR 等数值是当日快照，后续判断使用信号日重新计算的数值。
- 跟踪止损必须只升不降：`新止损 = max(上一日止损, 当日计算值)`。
- 加仓或买回前必须写明最高接受价和止损位；仓位按风险预算计算，不以摊低成本为理由。
