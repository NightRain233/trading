## 波段操作策略

### 底仓 + 浮动仓

```
底仓：6/9 买入的 300 股，ST 翻空才走
浮动仓：6/18 买入的 300 股，按波段信号卖出和买回
最大常规仓位：600 股
```

### 卖出信号（浮动仓）

| 指标 | 触发阈值 |
|------|------|
| RSI(21) | ≥ 65 |
| KDJ J | ≥ 80 |
| 距 ST | ≥ 3 ATR |

日线收盘时三项满足至少两项，下一交易日卖出浮动仓 300 股。

### 买回信号（浮动仓）

| 指标 | 触发阈值 |
|------|------|
| RSI(21) | ≤ 55 |
| KDJ J | ≤ 30 |
| 距 ST | ≤ 1.5 ATR |

仅在浮动仓已经卖出、ST 仍 LONG、ADX >25 时检查买回信号。日线收盘时三项满足至少两项，下一交易日价格不高于信号日收盘价时买回；高于该价格则取消，不追价。数量按风险预算计算，且买回后总仓位不得超过 600 股。

### 止损

**底仓（6/9 300 股）**：日线 ST 翻空 → 下一交易日全部离场。

**浮动仓（6/18 300 股）**：**双止损，哪个先到用哪个。**

```
止损 = min(EMA50, 最高收盘价 - N × ATR)
```

| KDJ 状态 | ATR 倍数 N | 说明 |
|----------|-----------|------|
| K<85 且 J<85 | **2.0** | 正常，给趋势呼吸空间 |
| K>85 且 J>85 | **1.5** | 超买，收紧止损近身保护 |
| K>90 且 J>90 | **1.0** | 极端超买，贴紧止盈 |

| 示例 | 情况 | 止损价 | 结果 |
|------|------|--------|------|
| 6/30 | 无极端超买，N=2.0 | min(1.869, 2.104-0.20)=**1.904** | 7/2 收盘 1.876 触发 ✅ |
| 原规则 | 只用 EMA50 | **1.869** | 7/2 擦边，至今未触发 ❌ |

双止损比单 EMA50 对阴跌更敏感，同时保留 EMA50 作为底线的保护作用。**每周日晚上重新计算止损价并更新条件单。**
